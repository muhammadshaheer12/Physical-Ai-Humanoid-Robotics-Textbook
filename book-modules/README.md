# Physical AI & Humanoid Robotics Textbook Assets

This repository contains all the code examples, URDF models, simulation worlds, configuration files, and other assets required to follow along with the "Physical AI & Humanoid Robotics Textbook".

## Structure

- `module_1_ros2/`: Assets for Module 1 (The Robotic Nervous System)
    - `src/`: ROS 2 Python source code
    - `launch/`: ROS 2 launch files
- `module_2_simulation/`: Assets for Module 2 (The Digital Twin)
    - `worlds/`: Gazebo/Unity world files
    - `models/`: Robot models and environmental assets
- `module_3_isaac/`: Assets for Module 3 (The AI-Robot Brain - NVIDIA Isaac)
- `module_4_vla/`: Assets for Module 4 (Vision-Language-Action)
    - `capstone_project/`: Capstone project files
